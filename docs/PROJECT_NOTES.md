# Project notes and submission checklist

## Project goal
Explore Formula 1 race and performance data through Tableau visualizations and supporting Python/SQL workflows.

## Included Tableau workbook
`tableau/F1_Race_Intelligence.twb` is the supplied workbook copied as-is. This package does not assert that its external data connection will resolve on another computer.

## Before submission
- [ ] Add the actual source dataset to `data/raw/` (check license and attribution).
- [ ] Run Python profiling and inspect its JSON output.
- [ ] Confirm SQL table and field names, then adapt and run analysis queries.
- [ ] Reconnect and test the Tableau workbook on the submission computer.
- [ ] Add dashboard screenshots and verified findings to the report.
- [ ] Add student name, enrollment number, course, and institution where required.
- [ ] Record the project walkthrough video explaining only work you personally understand and completed.
